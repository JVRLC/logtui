# Roadmap

LogTUI is currently an early MVP. The architecture is intentionally small while
leaving room for the features below.

## Next

- Standard input support for Docker, Kubernetes and journald pipelines
- Fast text search
- Independently tested query language
- Headless JSONL output
- JSON, JSONL and CSV exports

## Later

- Native Docker and Kubernetes integrations
- Saved filters and queries
- Stack trace grouping
- Configurable themes
- Statistics and level histograms
- OpenTelemetry log support

Follow progress or suggest improvements on
[GitHub](https://github.com/JVRLC/logtui/issues).
