# Roadmap

LogTUI continues to evolve with powerful filtering and modern terminal capabilities.

## Completed

- [x] Independently tested query language (`level:error service:api status:>=500`)
- [x] Headless JSONL and plaintext output (`--headless`, `--jsonl`)
- [x] JSON, JSONL and CSV exports (`--export`, shortcut <kbd>e</kbd>)
- [x] Native Docker container integration (`docker:container_name`)
- [x] Multi-line stacktrace grouping and elevation
- [x] Live log level distribution histogram
- [x] Wait for missing files creation (`--wait`)
- [x] Interactive level and source filters with click and keyboard shortcuts

## Next

- Native Kubernetes pod integrations
- Saved filters and query presets
- Configurable color themes
- OpenTelemetry and syslog formats support

[GitHub](https://github.com/JVRLC/logtui/issues).
